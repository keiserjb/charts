# Charts Chart.js

Provides a Chart.js renderer for the Charts module.

The Chart.js runtime is bundled in `library/chartjs/chart.umd.min.js` and is
used by default. Administrators can switch the source at:

`admin/config/content/charts/chartjs`

Supported library sources:

- Bundled with the module.
- CDN, using the configured pinned URL.
- Custom external URL.
